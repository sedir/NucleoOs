# Targeted lexicon for ANIMA's real spoken output (Brazilian Portuguese). Built from the pt reply catalog
# (firmware/components/nucleo_anima/anima_pt.c: PT_REPLIES fixed parts + PT_TERMS) and the pt {value} words
# (app_anima.cpp fill_system_value_pt, nucleo_tts_speak_time "pt"). The device replies are ASCII ("Nao sei",
# "Espaco no SD"); the text here carries the accents so the voice pronounces them, and slugify() folds them
# back to the same slug the firmware computes ("Não sei" -> nao_sei). Numbers, "e", "mil", "cem"... come from
# the mandatory pack (build_voice.py). Whole phrases where prosody matters; pieces for the variable parts.
# "slug<TAB>spoken text" lines give a lowercase slug an explicit reading (acronyms, units).
